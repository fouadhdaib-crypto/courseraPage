# coursera - Landing Page

A simple, responsive landing page inspired by online learning subscription platforms, built with **Bootstrap 5**.

## 🚀 Features

- Hero section with headline and call-to-action button
- 3-column features section (Unlimited Courses, Certificates, Learn at Your Pace)
- Pricing card section
- Responsive footer
- Fully responsive design (mobile-friendly via Bootstrap grid)

## 🛠️ Built With

- HTML5
- CSS3 (custom styling)
- [Bootstrap 5.3.3](https://getbootstrap.com/) (via CDN)

## 📂 Project Structure

├── index.html
├── style.css
└── README.md


## 💻 How to Run

1. Clone or download this repository
2. Open `index.html` in your browser — no build tools or installation needed

```bash
git clone <your-repo-url>
cd <repo-folder>
open index.html
```

## 📸 Sections

- **Hero** — Main headline with a "Try for Free" CTA
- **Features** — 3 key selling points in a grid layout
- **Pricing** — Simple monthly plan card
- **Footer** — Copyright info
